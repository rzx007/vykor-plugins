# 市场工具测试

`npm test` 只运行本目录的 Node 测试，不递归发现官方插件自己的测试。完整市场构建会在各插件的临时目录调用其已有检查。

- `pack.test.mjs`：来源清单、展示信息、组件入口、许可证和确定性归档。
- `checkouts.test.mjs`：外部固定提交、跨仓库隔离、目录边界和清理。
- `official.test.mjs`：用临时 Git 仓库执行真实构建入口，检查官方源码快照、实际提交、旧输出隔离、预览及发布拒绝；声明的 MCP 服务联通测试必须执行，失败后不生成插件归档或索引。完整生成的目录即使声明未来宿主版本，也不能包含根路径或点分段等无效来源。

测试使用临时仓库和目录，不发布 Release 或 Pages。来源和发布规则改变时，在对应测试文件中添加可观察行为；不要通过搜索实现文本来代替执行入口。

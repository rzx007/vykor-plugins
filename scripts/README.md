# 市场构建与发布

`npm run build` 从根收录清单开始，在临时目录运行插件构建与检查，最后把 ZIP、公开索引和构建凭据写入根 `dist/`。构建失败不会产生可发布凭据。

| 文件 | 用途 |
| --- | --- |
| `build.mjs` | 读取清单、清理旧输出、依次构建及打包、记录实际市场提交 |
| `sources.mjs` | 选择本仓官方临时快照或外部固定提交；官方快照只复制 Git 可见源码 |
| `checkouts.mjs` | 按仓库与提交创建外部检出，验证目录边界，并在本次构建后清理全部临时目录 |
| `lib.mjs` | 收录与公开来源校验；来源路径须为客户端接受的真实子目录，组件入口另按原规则检查；许可证、归档限额和确定性 ZIP |
| `provenance.mjs` | 记录 HEAD、工作区预览状态和索引摘要；发布时核对 main CI 及实际提交 |
| `verify.mjs` | 验证构建凭据、公开索引、归档摘要、大小和组件清单 |
| `check-publish.mjs` | 只读检查发布条件，不调用 GitHub |
| `publish.mjs` | 先检查发布条件，再上传不可变 Release；已发布版本仅接受相同摘要 |

临时源码与安装依赖属于 `.work/build-*/`，输出属于 `dist/`，两者均被 Git 忽略。官方插件工作区不承接市场构建的输出。来源解析与预览校验集中在对应模块；新规则在 `../test/` 添加回归测试，避免在插件源码内加入市场专用分支。

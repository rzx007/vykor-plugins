# src

编辑与自动保存流程。`editor.ts` 管理草稿、版本、保存调度及失败恢复，页面通过此控制器访问状态；不直接读写文件。新增流程继续放这里，回归测试放 `__test__/`。

加载场景时，界面返回 Excalidraw 整理后的实际场景作为显示基准；随后相同的异步变化回调不生成草稿或提交。这个基准不冒充服务端已保存的数据。明确未受理的 busy/hidden 保存进入等待状态，连续编辑只保留最新草稿，恢复后继续按原版本提交；版本冲突和结果未知仍停止自动保存。

同一画板的读取尚未完成时，也允许用户继续编辑；若保存被忙碌状态、权限或未知结果阻止，较新的读取结果不能清除新草稿。只有用户明确确认放弃草稿后才替换。

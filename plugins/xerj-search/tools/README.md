# 原生检索工具

| 文件 | 职责 |
| --- | --- |
| `index.mjs` | 注册 Search、Definition、Map、BatchSearch 四个宿主工具 |
| `search.mjs` | 选择原生调用、处理弱匹配和逐项状态、执行结果预算与回退 |
| `native-mcp.mjs` | 启动短期 xerj mcp，发送初始化和指定调用，停止进程；只允许四个只读上游名称 |
| `config.mjs` | 读取操作者配置、匹配当前项目、核对 corpus ledger、读取认证文件 |
| `evidence.mjs` | 解析原生结果，校验文件实际路径与当前原文，保留不同位置和片段 |

调用入口由 `context.cwd` 与 `context.plugin.dataDir` 提供，模型仅提供问题、符号和条数。配置属于操作者，索引属于独立搜索服务；插件只保存短期调用状态，不写记忆或索引。MCP 的初始化说明和工具描述不转给模型；每次调用在 finally 中关闭输入并停止子进程，取消也会回收。

原生排序、定义选择和窗口保持原样。去重仅消除相同文件、相同位置和相同片段；重复文本优先结合原生行号确定位置，无法消歧则返回未知行号。批量预算只留下 citation 时恢复其文件位置；没有正文与行号时只返回已核验文件和 `line:null`，交给 Grep/Read 继续定位。证据不得通过符号链接逃出项目，不返回私密路径或未能匹配当前原文的旧片段。目录与正文核验是插件自身检查，不承诺操作系统级沙箱。

0.2.1 只剥离明确的原生格式说明，保留普通方括号正文；页尾数量允许按原生预算账目核对已去重/丢弃的记录。定义标签和匹配行分别用于定位；唯一正文按当前文件重定位，重复正文先使用覆盖它的匹配行，再考虑唯一的定义后候选，仍有歧义则不填行号。核验要求连续原文，不把省略号两侧的不同区域拼接成证据。

每个命中新增 `readLine`，取实际返回片段 `startLine/endLine` 的中点；它是补读位置，不是引文行号。片段足够时无需再读；不足时先以该位置为中心读取最多 25 行，未知位置先 Grep。评测执行相同策略并保持每文件 4 KiB 上限，插件本身不自动执行宿主 Read。

普通结果限制8KiB，批量16KiB；批量始终保留每个输入位置和原生状态，适配层丢弃命中时另写原因。失败和 disabled 同样受预算约束，不能用半截搜索条件代替原条件。新增行为放在本目录，相应测试放在根 `__test__/`；不要添加上游反馈或写操作。

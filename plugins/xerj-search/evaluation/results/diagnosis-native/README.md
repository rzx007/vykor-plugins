# 原生漏检诊断记录

此目录保存 0.2.0 原生漏检调查的数据，不替代旧 benchmark。入口、推理、每题归因及限制见 [逐题报告](../../MISSES-NATIVE.md)。使用原冻结语料和索引，生产插件不变，无新模型 API 调用。

| 文件 | 用途 |
| --- | --- |
| `boundaries.json` | 11 道原证据失败题的实时原生回包、调用参数、0.2 解析与核验后的输出，逐层查看丢失 |
| `index.json` | 实际 mapping/settings、字段分词、各人工目标记录与关键文字存在性 |
| `variants.json` | 11 题各四种本地诊断：k=50 探查、禁用符号选段、语义改写、definition 能力短语；保留全部失败 |
| `controls.json` | 较短改写、中文关键词、语言过滤、增大/减小 full、hybrid 等补充探查；失败同样保留 |
| `adapter-bounded.json` | 对捕获回包离线修正格式解析和标签锚点，继续限制片段 1,500 字节与输出 8 KiB；没有提高原五题文件命中 |
| `bounded-controls.json` | 对事后选定查询组合重放原型解析与生产字节限额，不作为正式成绩 |
| `bounded-controls-live.json` | 选定组合按相同 1.5 秒、2,000 词、1,500 字节/片段、8 KiB 重新实时确认一次；原型解析未写入生产 |
| `oracle-keywords.json` | 将预先人工给 Grep 的正则转换为原生关键词的正向控制；含答案附近标识符，不能用作收益 |
| `cjk.json` | 引擎已有 CJK 双字分词的实际分析结果，未重建索引或测其召回 |
| `shell-span.json` | Shell 题符号范围、嵌套 execute 定义与目标行，解释为何增大 full 也没返回实现 |
| `window-policy.json` | 对原 96 条记录重新读取；同预算以已返回片段中点作为 Read 位置，确认证据 31.25% → 62.5% |
| `runtime.json` | 固定版本、源码引用提交、服务资源与停止状态，确认零新模型请求、零重建索引、未改生产插件 |
| `validation.json` | 题集、96 条重读记录、13 个索引锚点、六条有界实时控制及停止状态的最终核对 |
| `prototype-parser.txt` | 最终有界控制使用的解析原型文本，便于复现；生产工具未导入或使用它 |

诊断的大范围查询曾使用 15–30 秒上限、k=50 或无 MCP 词预算，目的是寻找目标位置，不能混入原速度或 top5 指标。`bounded-controls-live.json` 单独恢复原预算以验证选定方案；每项仅一次、热缓存、事后选择，不是新测试集成绩。

`variants.json` 的早期解析原型不完整；最终有界确认以 `bounded-controls-live.json` 的明确源码核验输出为准。原型只去掉已确认的格式说明、把定义标签用于锚点，随后仍执行生产路径、正文与字节核验。全部原始正文保留，便于复现。正式修复仍需另补真实格式的回归测试。

状态只在本次输出与临时服务里。新增诊断结果用新文件名，不能覆盖旧成绩或按输出改题。可复现的离线统计脚本放在上级 `evaluation/analyze-misses.mjs`，正式检索逻辑继续放在插件 `tools/`。
